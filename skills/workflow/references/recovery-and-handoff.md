# 恢复与交接

## 恢复

1. 运行 `doctor`，再显式读取任务、阶段、revision、门禁和工作项。
2. 用 `context render` 获取最小索引，按当前动作读取原始制品。
3. 对照事件与制品确认最后一次已提交或已验收的动作；不要仅凭聊天历史推断。
4. 未验收工作项保持待验收或返工，不自动视为完成。
5. 平台会话失效只影响执行载体，不改变任务、工作项或制品身份；平台恢复方式从 Platform Profile 增量指南读取。

## 人工等待

问题必须包含：当前阶段、已知事实、阻塞原因、可选方案、各方案影响、需要用户做出的明确决定。恢复后先记录决定，再继续流程。

## 会话交接

在任务制品目录维护简短交接文档，先注册为上下文，再执行 `context rebuild` 刷新索引。至少写明：

- 任务 ID、当前阶段和 revision；
- 当前目标与范围；
- 已完成并验收的事项；
- 进行中的工作项及 Owner；
- blocker、风险与开放问题；
- 关键制品和验证证据路径；
- 下一条可执行动作。

交接文档是索引，不复制大段代码、SPEC 或 Review 正文。
