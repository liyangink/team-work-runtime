# 测试协作

适用于单元、集成与 E2E。Junior 覆盖行为矩阵、用例、夹具和执行；Senior 挑战覆盖模型、失败路径、隔离性与假阳性；高风险、复杂并发或关键 E2E 结果由非作者 Expert 复核。

## 质量策略

- 把需求映射到正常、边界、失败、恢复和兼容路径；共享夹具由唯一 Owner 管理。
- 先证明测试能捕获目标问题，再确认修复有效；保存命令、环境和原始结果。
- 产品代码缺陷交给实施内容 Owner；测试策略缺口留给测试场景；环境问题如实标为阻塞并说明恢复条件。

## E2E 小循环

E2E 先判断适用性，再依次完成：测试设计、用例审查、夹具、实现审查、执行、结果复核。用例、夹具、脚本或执行问题留在该循环，不能以“测试通过”替代原始证据。
