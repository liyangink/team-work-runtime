# 明晰表达

读取 [公共输出规范](../clarity-guidance/output-standard.md)，按实际材料组织并自检；同一上下文可复用已读版本，来源/内容变化或新会话时重读。重要事实缺失就说明，不为补文案扩展调研、修复或授权。

用户需要确认关键选择、方向偏离或核心阻碍时使用 clarity-review，由它直接读取公共规范，无需再调用本入口重复改写。TWR 已自动送达必读短段，不要求主动调用两个技能；深入查阅只读所引用资源。

独立安装须同时携带同级 clarity-guidance；单复制本目录不自包含。以宿主实际返回的正文和资源基址确认来源，资源缺失时诊断并保留原用户要求，不创建写作死门。
