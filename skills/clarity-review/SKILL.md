# 明晰审阅

读取 [公共规范](../clarity-guidance/output-standard.md) 与 [审阅规则](references/review-rules.md)，不再调用写作入口重复处理。

先识别上下文：有明确 TWR 任务、阶段与范围时按审阅规则的 TWR 边界，沿用现有报告/方案/决定事实；已知 TWR 但事实缺失时标未知，不转成独立账本。独立审阅需持久记录、反馈或恢复时再读 [独立记录](references/standalone-records.md)；需要具体案例时读 [示例](references/examples.md)。

TWR 已自动带入适用必读段，不强制主动调用本技能。不得因能修就修、扩范围、联系人或部署；正式等待期间不调查、派发或推进。

独立安装须携带同级 clarity-guidance，核对宿主实际正文/基址；缺资源诊断，不增门禁。原记录优先，不改个人旧技能、不转接旧名调用。
