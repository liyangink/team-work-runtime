# 独立审阅记录与恢复

只用于 TWR 之外的持久审阅；[审阅规则](review-rules.md) 的选择、授权和表达边界仍适用。本文件合并授权来源 0.3.0 的 state-model 全部状态语义，不要求 JSON/YAML schema、代码账本或监管模块。

## 保存与身份

有待处理项、人工反馈或需保留历史时默认在本任务已授权的持久位置保存同一对象的一份完整记录，优先沿用原记录。每次反馈/产物/状态更新后先保存，再报告可恢复状态。短简报与账本分开并提供链接；无授权位置或保存失败时说明未持久保存，提供独立文件/附件式恢复入口，确实无法分离才在简报后清楚分隔附完整可复用记录，不遮首屏、不扩权限。

同一问题按语义和来源对应稳定 ID，语义修订增加 r1→r2，不按清单顺序匹配；不能确定是否同项时说明疑点、不继承接受。拆分/合并建立新 ID 和来源关系，不继承批准；替代和消失保留历史，检查尚未履行的义务，不用新原文覆盖旧反馈。

| 分开保存的事实 | 内容 |
| --- | --- |
| 身份与来源 | 对象/范围/规则版本、ID/类型/当前修订/原文/适用条件、意图与比较基线、实际快照、证据摘录/位置/依赖及未查范围 |
| 去向与行动 | 本轮主去向、影响程度、证据状态、核心阻碍标记、调查/纠偏动作、责任角色、完成条件、触发及最晚准备阶段/条件 |
| 方向反馈 | 待审与否、历史原句、可取得的确认人/时间、批准或拒绝的修订/范围/条件；无实际身份/时间则留未知 |
| 修改落实 | 未开始/进行中/已落实，具体位置与快照；落实只表示所指工作完成 |
| 产物符合性 | 相符/偏离/未验证，对照的已确认要求与核对范围 |
| 证据/测试验证 | 已核实的证据范围、实际取得的测试结果及未验证部分；不得由方向状态推导 |
| 展示与恢复 | 已展示修订、实际反馈范围、代理核查证据、待补证据、下一进入条件与具体问题；展示不等于已读/接受 |

新方向默认待审。只对明确接受的修订/范围/条件记录接受；沉默、自评、测试不打勾，含糊反馈只保留可证实部分并澄清。当前修订/状态与上次接受修订/条件分别保存，方向可为待审、已接受、要求修改、已拒绝、待澄清、需重审、已撤回；方向、落实、符合性和验证四维不得压成一个状态。

## 当前快照与状态迁移

收到反馈或恢复前，重读原记录和当前产物、核对快照及相关依赖，再重算受影响项和简报。证据来源变化时重查，批准使用前再次核对其版本/依赖。无法取得稳定快照只能标历史视图/当前待核，不沿旧接受放行，不把旧数量叫当前待决定；历史遗失不猜批准。

| 事件与证据 | 记录与简报变化 |
| --- | --- |
| 明确接受 r1 | 保留选择及条件，落实/符合性/验证仍各自未知，除非另有证据；接受不授权部署 |
| 要求修改 r1，r2 按指令落实 | 保留 r1 修改原句、记 r2 落实/符合性；无明确新版接受不标接受。无新取舍报结果复核/已核对及未验证，不能算新方向问题 |
| 已接受选择的语义、范围、条件、代价或依赖改变 | 当前修订升级，旧接受原文/条件保留，只重审受影响项；说明旧决定、变化与现在需回答什么 |
| 排版/定位或经核对等价措辞改变 | 更新快照/定位及等价依据，保留原选择；无新方向问题 |
| 无关区域改变 | 说明比较范围，保留未受影响选择，不清空全账本 |
| 产物违背已确认基线但无新取舍 | 记偏离、纠偏动作及是否已修/相符；报告阻碍或纠偏，不重问旧方向。审核授权不自动允许修复 |
| 高影响未知尚未补证据 | 代理待核查并保留核心阻碍、已查范围/升级时点，不制造“接受未知”勾选 |
| 事实核查解除阻碍 | 记录新证据/快照，解除旧标记；只有实际新取舍才重新分流 |
| 条件/执行项到最晚准备门槛仍不可执行 | 保留去向，增加阻碍及责任待定说明，提前可见，不等事故或上线当刻 |
| 快照与记录不同但差异未核 | 保留历史反馈，只报历史视图/当前待核，核对后才能生成当前简报 |
| 候选消失、撤回或被替代 | 保留来源关系及历史，仍有未履行义务就显示缺口，不因删项撤销承诺 |
| 规则或模型版本改变 | 重扫候选，新增发现入账；不自动清空接受，缺字段不反推落实、符合性或测试已过 |

简报从当前记录投影：人工问题只数真实新取舍，阻碍只数当前安全/数据/可执行性障碍，同项有两种标记不重复提问。可见/未展示、完整候选、仍有效和条件项若呈现数字须重算，不手抄旧标题，不强求每轮统计。发送前核对证据、四维、快照和保存状态，不能留精确却过期的当前总表。
