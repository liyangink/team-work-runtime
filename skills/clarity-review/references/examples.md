# 明晰审阅示例

四例全部虚构，源句/版本标签只定位本文材料，不是真实哈希、文件路径、API 承诺或测试结果，反馈不代表当前用户批准。真实使用须读取当前原件及实际快照。普通简报只给当前选择和阻碍，完整资料另存/另链；独立记录遵循 [独立记录](standalone-records.md)，TWR 沿已有报告和任务事实，不把例中 ID 当作 Runtime 字段。

## A. 独立需求审阅：信息导出

材料：A1 已确认“仅信息负责人可导出”；A2 字段限姓名、机构、跟进状态；A3 需记操作者、时间和范围。draft1 的 A4 扩至被分配协作人，A5 字段/审计与 A2–A3 相同。A1–A5 未定义协作资格生命周期，未查身份规范。

简报：需要决定是否允许被分配协作人导出。建议先明确资格规则再扩大授权；直接依据 A1→A4，收益数据未有。

- [ ] D-A-1 r1：接受扩权、要求修改或拒绝？
- 核心阻碍 D-A-2：资格授予/撤销未定义；代理先查既有身份规范，最晚在授权方案定稿前升级，不为此默认新建系统。

A2–A3 的方案一致性是事实核验，不勾选。完整记录保存两候选、证据、搜索范围与实际快照，首屏不贴总表。

虚构反馈：“接受 D-A-1 r1；仅负责人授予/撤销资格，移除成功后新导出请求立即失权。”记录范围只限新请求，不能推断在途导出；方向反馈有了，实现/测试仍未验证。draft2 再加入部门员工时，D-A-1 r2 定向重审，新增资格缺口先核查；协作人旧规则仍有效但不覆盖部门员工。仅换段落则核对等价，更新定位并报无新方向。

## B. 独立方案审阅：异步创建

材料：B1 要求最终得到成功/失败，没有规定必须同次响应；B2 旧调用方以 201 为成功。draft1 的 B3 返回 202 和任务标识，B4 查询处理中/成功/失败，成功才是最终完成。本例接口和状态只是虚构方案，未有迁移或性能证据。

简报：需要决定能否先受理再查询最终结果；建议隔离新版本以保留旧语义。方向项 D-B-1，兼容缺口 D-B-2 为代理待核查＋阻碍，先查既有版本策略，定稿前须有兼容路径。不能声称异步必然违背 B1。

虚构反馈接受新版本并要求旧接口保持原语义、迁移前不移除；保存条件，兼容转为执行义务，文字有承诺不等于实现。draft2 却在后台未完成时返回成功并显示完成：沿基线纠偏，不让人再选旧方向；只有作者提出实际新取舍时才提新修订。旧接口条件仍保留、实现未验证。

## C. TWR 代码审阅：隔离条件

材料：C1 已确认所有用户仅访问同一隔离域，无管理者例外。旧片段在域不同就拒绝，新片段仅在域不同且不是管理者时拒绝；无外围检查和测试证据。

简报：无新方向选择；局部检查的管理者绕过偏离 C1，是核心阻碍。已有审查报告保留前后条件、影响边界和最小纠偏建议；仅审核授权不实施修复，不把局部绕过说成端到端已证实。

虚构修改指令：“恢复所有用户的同域限制。”若修复已获授权，恢复后分别说明：方向沿 C1、无新版接受；修改已落实；局部条件相符；全链路/测试未验证。给现有报告/方案入口，不建独立账本。无新选择也不能绕过当前人工门或变后指纹重批，不能自动调用决定工具。批准正文不为反馈记账而改写，正式等待不继续核查/派发。

等价提取局部变量核对后不重问旧方向；再次引入绕过就重新报告纠偏义务，不能以旧项处理过为由忽略。旧拒绝不能改成接受例外，Lead 不改成员技术结论。

## D. 独立多问题恢复：数据切换演练

纯虚构材料：D1 已确认顺序“切流→在途写入完成→以新存储为权威回流”；draft1 的 D2 同时写“切流前并行回流”与“完成写入后回流”。D3 要求验证写入路径，所给资料未定义工具和判据。反馈已要求缩窄某操作限制，draft2 的 D4 已落实，但旧清单仍把它叫待决定。其余候选有阈值、观察期、职责、异常预案及保底路径。

简报：无新方向选择，有顺序冲突和验证缺口两个执行阻碍。D2 按 D1 纠偏；D3 先查现有工具、监控和安全验证证据，不凭空设计生产写入，最晚演练前解决。实际核查可能改变数量，本例两项仅对应所列材料。

D4 为要求修改已有反馈/文字落实/符合性待核/新版未接受，不再计方向问题。阈值在已定口径下是执行项；若改变风险上限才是取舍。责任未知记待确定角色，不招人或发消息；预案记触发与最晚准备阶段，切换阶段开始前仍不可执行就提前显示阻碍，不等事故。

恢复先重读 draft2 和原账本、核对真实快照再生成简报，不沿旧“全部待决定”标题。若补证据解除 D3 就更新阻碍，若快照无法确认只给历史视图/当前待核；规则升级不抹掉反馈，缺字段不当测试通过。保存失败提供独立恢复入口、说明限制，不让完整账本遮简报。

## 核对这些行为

核对九类候选是否完整、五去向是否先查基线/证据、重要未知与预案是否及时可见；确认只让人作实际取舍，要求修改/落实/符合性/验证/接受没有混淆。检查当前快照和反馈后重新投影，原证据不支持的收益、责任、范围和结果仍保持未知，不靠格式或勾选证明正确。
